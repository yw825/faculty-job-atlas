# Faculty Job Atlas — job-data

Scrapes faculty job postings for every school in `schools_master.csv` and
feeds `postings.json` (the map at the repo root).

## Nightly refresh

The whole pipeline runs on its own every night. See **REFRESH.md** for
schedule, what each stage does, and how to check a run's log.

## Core files

- **schools_master.csv** — one row per school: `school_id`, `name`,
  `country`, `base_url`, `careers_link`, `ats_platform`, `notes`. The
  source of truth for which page each school's postings are scraped from.
- **posting_first_seen.csv** — the date each posting URL was first
  observed. This is the only record of that; a posting scraped today looks
  identical whether it went up yesterday or last year. Never delete it.
- **job_postings_lib.py** / **job_info_lib.py** — the scraping library
  every per-school script imports: platform adapters (Workday, PeopleSoft,
  Oracle, ADP, SchoolJobs, Interfolio, and more), title/keyword extraction,
  and the checkpointing that makes a re-run only pay for what's new.
- **school_job_posts_code/**, **school_job_info_code/** — one script pair
  per school. Generated by `generate_school_scripts.py`; hand-edited where
  a school needs something the generic scraper can't do.
- **school_job_posts/**, **school_job_info/** — the scraped CSVs those
  scripts write, one file per school.

## Pipeline scripts (what `nightly_refresh.sh` runs, in order)

1. `run_all_countries.py` → `run_school_scrapers.py` — re-scrape every
   school's listing
2. `clean_job_posts.py` — strip furniture (nav, search pages, share
   widgets) from the link sets *and* their checkpoints
3. `run_all_countries.py --stage info` — fetch detail for newly-seen
   postings (checkpointed, so old ones aren't re-fetched)
4. `prune_stale_info.py` — drop info rows whose URL didn't survive step 2
5. `build_map_data.py` — rebuild `postings.json`, stamp first-seen dates
6. commit + push

## Maintenance tools (run by hand, as needed)

- **generate_school_scripts.py** — creates a new school's script pair
- **rediscover_careers.py** — finds a school's real careers page from its
  homepage, when the stored link goes dead or turns out to be wrong
  (multilingual: EN/ES/IT/CA/TR/DE/FR/NL/Nordic/PL/PT)
- **verify_careers_links.py** — checks whether each school's `careers_link`
  itself resolves (ok/empty/review/broken)
- **verify_posting_links.py** — fetches every stored *posting* link for a
  set of schools and classifies it (posting/furniture/dead/blocked)
- **diagnose_low_yield.py** — classifies *why* a school returns few
  postings (inline listing, paginated, JS-only, blocked, wrong URL...)
- **validate_and_apply.py** — before trusting a structurally-detected link
  pattern, opens two of its links and checks they read like real postings
- **backfill_primary_keyword.py** — replays a keyword-extraction
  improvement over already-scraped titles, without re-scraping
- **deep_probe.py** — the structural "these links share one URL shape"
  posting-pattern detector; also imported live by `job_postings_lib.py`
